
# World Currency Knowledge

**Developed by: ARYANRAJ MALEPU**

## 🌍 Project Overview

**World Currency Knowledge** is an educational web-based **currency encyclopedia** created to provide users with an organized source of information about currencies, foreign exchange, cryptocurrency, currency history, and related financial terminology.

The project is designed to make learning about currencies easier by dividing information into dedicated sections and individual pages. Users can explore major world currencies, understand foreign exchange concepts, learn about the history and types of currencies, and refer to a glossary of commonly used terms.

The project focuses on presenting financial and currency-related knowledge in a simple, structured, and accessible format.

## 🎯 Project Objective

The main objective of **World Currency Knowledge** is to create an educational platform where users can explore and understand the world of currencies without needing to search through multiple sources.

The website organizes information into different sections covering:

* World currencies
* Major currencies
* Foreign exchange
* Currency exchange
* Cryptocurrency
* Currency history
* Currency types
* Currency terminology
* Individual currency information

## 📚 Main Sections

### Exchange

Explains currency exchange and the relationship between different currencies.

### Cryptocurrency

Provides an introductory section covering digital currencies and cryptocurrency concepts.

### Currency History

Explores the historical development of money and currencies and how monetary systems have evolved over time.

## 🚀 How to Run

The project is a static web application and does not require a backend server or database.

### Method 1 — Open Directly

Download or clone the repository and open:

```text id="currencyopen"
index.html
```

using a modern web browser.

### Method 2 — Clone Using Git

```bash id="currencyclone"
git clone https://github.com/ayvan6/world-curreny-knowledge.git
```

Enter the project directory:

```bash id="currencycd"
cd world-curreny-knowledge
```

Open the website:

```bash id="currencylinux"
xdg-open index.html
```

## 🌐 Run Using a Local Server

For development or testing, you can use Python's built-in HTTP server:

```bash id="currencyserver"
python3 -m http.server 8000
```

Then open:

```text id="currencyurl"
http://localhost:8000
```

The browser will display the project's main page.
